# AstrBot WOT Plugin

AstrBot 插件，用于查询《坦克世界》玩家效率

## 目录说明

- `main.py`: AstrBot 插件注册与命令入口。
- `src/application`: 应用层，负责编排命令处理、查询流程和报表流程。
- `src/domain`: 领域模型与领域枚举。
- `src/infrastructure`: 基础设施层，包含网络客户端、解析器、仓储与网关实现。
- `src/infrastructure/api_clients`: API客户端实现。
- `src/settings`: 配置常量与消息模板。
- `src/tasks`: 定时任务入口（例如坦克数据同步调度）。
- `resources/static`: 模板、字体和静态数据。
- `数据存储`: 绑定数据和坦克数据存储在 `data/plugin_data/astrbot_plugin_wot/data/` 目录下。
- `运行时产物`: 生成的 HTML 和图片 URL 缓存存储在 `data/temp/astrbot_plugin_wot/report/` 目录下。

## 命令说明

### 基础命令

- **帮助**：以图片显示所有可用命令、别名及其功能说明
  - 示例：`/帮助` 或 `帮助`
- **wot绑定**：绑定玩家游戏名称到当前QQ账号
  - 示例：`/wot绑定 玩家名称` 或 `wot绑定 玩家名称`
- **效率** / **盒子效率**：查询盒子页面基础效率数据（文本返回）
  - 玩家名称可省略，省略时查询当前 QQ 账号已绑定的玩家
  - 示例：`/效率` 或 `/效率 玩家名称` 或 `效率` 或 `效率 玩家名称`

### 战绩报表

- **今日效率** / **今日战绩**：查询今日效率和战绩
  - 示例：`/今日效率` 或 `/今日效率 玩家名称` 或 `今日效率` 或 `今日效率 玩家名称`
- **昨日效率** / **昨日战绩**：查询昨日效率和战绩
  - 示例：`/昨日效率` 或 `/昨日效率 玩家名称` 或 `昨日效率` 或 `昨日效率 玩家名称`
- **两日效率** / **两日战绩**：查询两日效率和战绩
  - 示例：`/两日效率` 或 `/两日效率 玩家名称` 或 `两日效率` 或 `两日效率 玩家名称`
- **三日效率** / **三日战绩**：查询三日效率和战绩
  - 示例：`/三日效率` 或 `/三日效率 玩家名称` 或 `三日效率` 或 `三日效率 玩家名称`
- **百场效率** / **百场战绩**：查询百场效率和战绩
  - 示例：`/百场效率` 或 `/百场效率 玩家名称` 或 `百场效率` 或 `百场效率 玩家名称`

以上战绩命令的玩家名称均可省略；省略时使用当前 QQ 账号的绑定玩家。

### 管理命令

- **同步坦克** / **更新坦克**：融合官网与 WotInspector 的坦克信息
  - 示例：`/同步坦克` 或 `同步坦克`

### 车库与环线查询

- **车库** [玩家名称] [等级] [类型]：查询玩家车库的坦克战绩，并可按等级、类型筛选
  - 查询结果以图片返回
  - 玩家名称、等级、类型均可选，可单独或组合使用，顺序不限
  - 类型支持：轻坦、中坦、重坦、坦歼、火炮及其完整名称
  - 仅统计 7-11 级，按场次排序展示前 30 辆；显示场次、胜率、场均击毁、场均伤害、场均经验和环数，不显示 WN8
  - 官方接口只返回至少参加过一场战斗的车辆；未战斗车辆不会出现在列表中
  - 示例：`/车库`、`/车库 10级`、`/车库 重坦`、`/车库 玩家名称 10级 重坦`
- **坦克生涯** [玩家名称]：查询游戏官网标准模式生涯统计
  - 按官网布局显示总成绩、平均每场战斗数据、成绩记录、MB 等数据
  - 等级分布完整显示 1-11 级
  - 显示按等级、坦克类型、国家划分的战斗坦克分布
  - 示例：`/坦克生涯`、`/坦克生涯 玩家名称`
- **环线** / **标伤** [坦克名称]：查询坦克一环/二环/三环标伤阈值（近7天）
  - 支持简称模糊查询；匹配多辆坦克时会返回全部结果
  - 查询结果以图片返回
  - 坦克名称必填
  - 示例：`/环线 59`、`/环线 野牛` 或 `标伤 鞭蛇`

车库与生涯使用游戏官网玩家统计接口；环线查询使用坦克营地（WoT Box）接口。
两个命令都优先使用绑定关系中的账号 ID，未绑定或指定其他玩家时会搜索玩家。

### 坦克信息与坦克对比

- **坦克信息** [坦克名称]：查询坦克的火力、机动、视野等百科属性
  - 坦克名称必填
  - 示例：`/坦克信息 59式`
  - 包含车辆图片，并按火力与炮控、生存与防护、机动、视野与隐蔽分类展示；火炮与发动机参数分别合并到火力、机动卡片
  - 详细参数包含装填、扩圈、俯仰角、装甲、地阻、倒车、隐蔽系数等
  - 名称模糊匹配到多辆坦克时会返回编号列表，回复编号即可继续查询（60 秒内有效）
- **坦克对比** [坦克A] [坦克B]：对比两辆坦克的主要属性
  - 坦克A和坦克B均必填，两辆坦克名称之间需要保留空格
  - 示例：`/坦克对比 59式 查狄伦 25t`
  - 不支持无空格连写
  - 支持简称输入；两辆坦克分别匹配到多个结果时，会依次返回编号列表供选择

百科与对比优先使用坦克营地完整百科数据并缓存 24 小时；接口不可用时，自动降级为每日同步的游戏官方/WotInspector 坦克资料。

### 命令使用说明

所有命令都支持两种使用方式：

- **带唤醒词**：使用 `/` 前缀，例如 `/效率`
- **不带唤醒词**：直接输入命令，例如 `效率`

对于官方QQ机器人，需要先@机器人，然后再输入命令，例如：`@QQ机器人 效率` 或 `@QQ机器人 /效率`

## 说明

### 插件配置

在 AstrBot 管理面板中可以配置以下选项：

| 配置项             | 说明                            | 默认值     |
| --------------- | ----------------------------- | ------- |
| 报表缓存有效期（秒）      | 短时间内重复查询同一玩家时使用缓存             | `60`    |
| 缓存最大条目数         | 缓存的玩家报表数量上限                   | `100`   |
| 并发请求等待超时（秒）     | 当多个用户同时查询同一玩家时，等待其他请求完成的最大时间  | `30`    |

### 图片渲染

图片渲染使用 AstrBot 的 T2I（文本转图片）服务，HTML 报表通过 T2I 服务转换为 JPG 图片返回。

默认使用 AstrBot 官方 T2I 服务，无需额外配置。如果官方服务响应较慢或不稳定，可自行部署本地 T2I 服务：

```bash
docker run -itd -p 8999:8999 soulter/astrbot-t2i-service:latest
```

部署后在 AstrBot 仪表盘 → 配置文件 → 系统中，将「文本转图像服务 API 地址」改为你的自部署地址（如 `http://localhost:8999/text2img`）。详见 [自部署文转图服务文档](https://docs.astrbot.app/others/self-host-t2i.html)。

### 依赖说明

- `jinja2>=3.1.6`：HTML 报表模板渲染
- `bs4>=0.0.2`：偶游盒子页面数据解析
- `schedule>=1.2.2`：每日定时同步坦克数据
- `aiohttp>=3.11.18`：异步 HTTP 客户端
- `pycryptodome>=3.20.0`：坦克营地接口响应解密（DES）

### 开发与测试

安装开发依赖：

```bash
pip install -r requirements.txt -r requirements-dev.txt
```

运行测试（测试使用 `data.plugins.astrbot_plugin_wot.*` 导入路径，需在 AstrBot 项目根目录执行）：

```bash
python -m pytest data/plugins/astrbot_plugin_wot/tests -q
```

静态检查：

```bash
ruff check .
```
